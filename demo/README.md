# Interactive Demo: Credit Risk Decision Engine

Folder ini berisi aplikasi interaktif berbasis web menggunakan **Streamlit** untuk mendemonstrasikan kapabilitas model *Credit Risk Assessment* secara langsung (*real-time inference*).

## Menjalankan Aplikasi Lokal

```bash
# Instal streamlit jika belum terpasang
pip install streamlit

# Jalankan aplikasi
streamlit run demo/app.py
```
